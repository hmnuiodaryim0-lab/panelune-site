Getting started

  1. Open Wi-Fi Transfer in Panelune.
  2. Open the displayed local address on a computer connected to the same network.
  3. Choose whether you are importing comics or novels.
  4. Select files or folders to transfer.
  5. Open your library and start reading.

Common questions

Importing books

In iPad version 1.1.1, use Link Folder to select a folder through Files, or Wi-Fi Transfer to send books from a computer on the same local network. Link Folder keeps books in their source folder; Wi-Fi Transfer saves an imported copy in Panelune. For novels, select a complete EPUB file rather than individual files from inside it.

Wi-Fi Transfer

Connect your device and computer to the same trusted local network. Allow local-network access when prompted, open the address shown in Panelune, and keep the app open while transferring. Stop Wi-Fi Transfer when you finish. If the address does not open, restart Wi-Fi Transfer and try the new address.

Linked Folders

Use Linked Folders to keep supported files in a folder and make them available to your Panelune library. Follow the in-app instructions when linking or updating a folder.

EPUB, PDF, CBZ, and CBR compatibility

Use EPUB for novels, PDF for documents, and CBZ or ZIP archives containing supported images for comics. DRM-protected, encrypted, damaged, or unsupported files may not open.

The current comic archive reader supports ZIP-based archives, not RAR-based CBR files. Use CBZ/ZIP instead; changing a file extension does not convert its format.

Vertical scrolling

Panelune supports page-by-page reading and continuous vertical scrolling. Choose the reading mode that works best for the book you are reading.

Private Library

Private Library is a separate library for selected books. Access uses the device’s authentication, such as Face ID, Touch ID, or the device passcode where available. It does not require a separate Panelune account.

Panelune Pro

Troubleshooting

  • Restart the app and retry the action.
  • Check that your device has enough available storage.
  • Check that the file is supported and is not damaged.
  • For purchase issues, use Restore Purchases before contacting support.

Offline reading and your books

Imported books can be read offline. Panelune does not require an account or operate a developer-hosted cloud library. Files linked from a cloud file provider may need to be downloaded through that provider before they are available offline. Purchases and purchase restoration require access to Apple’s services.

Panelune does not provide or distribute books. Import or link only books you own or have permission to use.
